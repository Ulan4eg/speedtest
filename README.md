# Замер скорости интернета: N последовательных скачиваний одного URL.

Пример:\
    ```python speedtest.py https://placehold.co/3000x2000.jpg ``` \
    ```python speedtest.py https://placehold.co/3000x2000.jpg -n 5``` - число запросов\
    ```python speedtest.py https://placehold.co/3000x2000.jpg --warmup 2``` - число прогревочных запросов\
    ```python speedtest.py https://placehold.co/3000x2000.jpg -j 4``` - число потоков\
    ```python speedtest.py https://placehold.co/3000x2000.jpg --no-cache-bust``` - не обходить кэш
